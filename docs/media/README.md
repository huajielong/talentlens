# README 演示素材

这些图片是客户版实际界面的截图，使用隔离验收环境中的虚构公司、人才与模拟模型结果。不是模型质量或招聘效果证明。

- `workspace-review.jpg`：岗位、绿色账号文字、评估详情与人工复核。
- `team-management.jpg`：团队管理、预算与审计。
- `first-run.jpg`：首次初始化。
- `product-tour.mp4`：26 秒、1280 × 720、H.264、无音轨的截图导览。0–12 秒纵向浏览岗位评估与复核截图；12–20 秒团队管理；20–26 秒初始化。

视频通过 FFmpeg 将实际截图编码，第一段做纵向平移以保持正文可读。它不是操作录屏，不展示真实 API 调用。后续录制端到端演示时，应使用隔离演示账号，隐藏密钥、个人资料和客户岗位信息。
